# Домашнее задание: Автотесты для SauceDemo с использованием Page Object Pattern


# Чек-лист тестирования приложения SauceDemo


## 1. Авторизация (Страница входа)
- [ ] Успешный вход с валидными данными (`standard_user` / `secret_sauce`).
- [ ] Попытка входа с неверным паролем (отображение ошибки).
- [ ] Попытка входа с неверным логином (отображение ошибки).
- [ ] Попытка входа с пустыми полями логина и пароля.
- [ ] Попытка входа заблокированного пользователя (`locked_out_user`).
- [ ] Попытка входа пользователя с задержкой (`performance_glitch_user`).
- [ ] Проверка закрытия иконки ошибки (крестик).

## 2. Каталог товаров (Inventory)
- [ ] Отображение списка товаров (6 штук).
- [ ] Сортировка товаров по имени (A to Z).
- [ ] Сортировка товаров по имени (Z to A).
- [ ] Сортировка товаров по цене (Low to High).
- [ ] Сортировка товаров по цене (High to Low).
- [ ] Добавление одного товара в корзину (изменение кнопки на "Remove", появление счетчика).
- [ ] Добавление всех товаров в корзину.
- [ ] Удаление товара из корзины прямо из каталога.
- [ ] Переход в карточку товара по клику на название или картинку.

## 3. Карточка товара (Item Details)
- [ ] Отображение названия, описания и цены товара.
- [ ] Добавление товара в корзину из карточки.
- [ ] Возврат в каталог по кнопке "Back to products".

## 4. Корзина (Cart)
- [ ] Переход в корзину по иконке тележки.
- [ ] Отображение добавленных товаров (название, описание, цена, количество).
- [ ] Удаление товара из корзины (кнопка "Remove").
- [ ] Нажатие кнопки "Continue Shopping" (возврат в каталог).
- [ ] Нажатие кнопки "Checkout" (переход к оформлению).

## 5. Оформление заказа (Checkout)
- [ ] Ввод валидных данных (First Name, Last Name, Zip Code).
- [ ] Попытка продолжить оформление с пустыми полями (ошибка).
- [ ] Попытка продолжить оформление без Zip Code (ошибка).
- [ ] Проверка страницы "Checkout: Overview" (итоговая сумма, налог, кнопки "Cancel" и "Finish").
- [ ] Нажатие кнопки "Finish" (успешное завершение заказа, сообщение "Thank you for your order!").
- [ ] Возврат на главную страницу после завершения заказа ("Back Home").
- [ ] Отмена оформления заказа (кнопка "Cancel").

## 6. UI / Визуальное тестирование
- [ ] Проверка отображения элементов на разных разрешениях экрана (мобильная версия, планшет, десктоп).
- [ ] Проверка работы бургер-меню (открытие, закрытие).
- [ ] Проверка ссылок в бургер-меню (All Items, About, Logout, Reset App State).
- [ ] Проверка работы кнопки "Reset App State" (сброс корзины и состояния кнопок).
- [ ] Проверка выхода из системы (Logout).
